# Programs (scope & sequence)

Each file is a **40-week, full-year program** (4 WA school terms × 10 weeks) for one
year level + subject. Worksheets are generated from these, in order. Each week names:

- **Focus** — the new learning.
- **Retrieval** — earlier weeks revisited in the warm-up (spaced practice).
- **Challenge** — the stretch beyond year level.
- **Status** — `✅ written` / `⬜ planned`.

English weeks name the **content text** (science / civics / history / geography /
economics) that carries the literacy skill.

Every program ends with a **Curriculum coverage check** mapping each part of the WA
syllabus (see `curriculum/year-XX.md`) to the weeks that teach it. When you change a
week, keep the coverage check accurate — every content area must stay covered.

Week 10 of each term is a review + assessment week; week 40 is the end-of-year
assessment and reflection.
