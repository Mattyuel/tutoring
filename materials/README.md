# Materials

Reusable resources that worksheets can draw on.

| Folder / file | Purpose |
|---|---|
| `passages/` | Stand-alone reading texts (with year level, topic, word count, source notes in a header) |
| `fact-sheets/` | Verified facts for recurring topics (WA geography, government, science) |
| `images/` | Diagrams/photos referenced by worksheets (check licence; note source in filename or a `SOURCES.md`) |
| `data/` | Small data sets (CSV) for statistics and graphing tasks |

When a worksheet's reading passage is good enough to reuse, copy it into `passages/`.
